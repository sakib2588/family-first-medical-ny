# Inner-page capture notes (2026-10-31)

Method: tools/capture.mjs (phone 390x844@2x first, desktop 1280x800), WAIT=domcontentloaded SETTLE=6000 (acpny/doctor retried the same way; WAIT=load times out there). Phone screenshots read as 3-tile strips (first ~2500 css px) plus meta.json (forms, h1/h2, tel links, fixed/sticky elements). Desktop folds viewed for only 8 pages. Flow walk: tools/explore-flows.mjs (clicks only, no typing, nothing submitted); logs in nao-appt/steps, tribeca-appt/steps, pafl-appt/steps. Tracker clues = names found in the post-load DOM (static; real network calls not inspected, so counts are a floor).
Folders: <site>-<pagetype>/{phone,desktop,html,meta.json}. `_run-*.log` = capture logs.
