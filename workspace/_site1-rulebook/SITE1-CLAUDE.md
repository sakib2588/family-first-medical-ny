# Site1

Lead-generating websites (and microsites) for NYC-area home-service trades. The goal is leads, not pages.

Read `vault/wiki/index.md` first. It holds the project decisions, the distilled course knowledge, the red lines (what we never do) and open questions. Update the vault and `vault/wiki/log.md` after any decision or ingest.

Skills are in `.claude/skills/` (design-taste-frontend, impeccable, awesome-design-md, playwright-cli, shadcn). Pick skills and MCP tools with `.claude/skills/site1-skill-router` (Stitch MCP for UI ideation; one skill or tool per job, which pairs never run together, which skills are off-limits for lead sites). Stack: Astro + Tailwind, one config-driven template.
