# Flaw register (deduplicated across all reference and premium sites)

Date: 2026-10-31. Built from: 02-analysis/*.md, 01-research/sites/*/notes.md, 01-research/inner/NOTES.md, 01-research/premium/*/notes.md, 01-research/legal/*/analysis.md, _digests-site1/. Not legal advice; every legal/claims fix is "verify with counsel".

## How to read
- Severity: H = hurts a visitor's main task, or creates privacy/legal/safety exposure; M = real quality loss; L = polish.
- Count = number of sites where the flaw was seen. REF = the 14 reference sites (FF base, ACP, MSC, NAO, NVP, NYP, NYU, OM, PAR, PAFL, SUM, TIA, TRI, YAN). PRM = the 10 scored premium sites (BB, CAS, CITY, CLT, GS, LO, ORAL, ROCK, SFP, TJ). Counts are my tally from the notes and are approximate (+/-1); "FF" is the base site we may be rebuilding, so flaws seen there are flaws to NOT carry over.
- Evidence column: file paths under 01-research/ (sites/X = 01-research/sites/X/notes.md; inner = 01-research/inner/NOTES.md; legal/X = 01-research/legal/X/analysis.md; premium/X = 01-research/premium/X/notes.md) and 02-analysis/ files.
- Honest limits that apply to every row: text and static screenshots only; load times are headless-capture numbers (noisy, not field data); tracker names are static DOM hits, not network traces; no traffic data; no user testing.
